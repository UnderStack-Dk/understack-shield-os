# Roadmap

## Shield MVP 0.1 — foundation (current)

Repository governance, security/privacy framing, architecture model, contribution workflow and decision-record process. No implementation scope is committed.

## Next discovery milestones

1. Platform and immutable-base evaluation.
2. Threat-model refinement and security-space boundaries.
3. Privacy/data-flow review, including optional AI and Pocket paths.
4. Prototype planning after ADR approval.

Milestones represent planning horizons, not release commitments. Features, dates, and development assignments will be created only after the owner approves the initial discovery outcomes.
