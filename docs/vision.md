# Product vision and scope

## Vision

UnderStack Shield OS aims to make a security-conscious personal computer understandable and controllable: local by default, restrictive by default when risk is high, and explicit whenever an action crosses a trust boundary.

## Intended outcomes

- A Linux-based desktop platform with an immutable/atomic base concept and safe recovery path.
- Clear separation between system, applications, data, devices, networks, and AI agents.
- Security controls that can contain, explain, and help investigate suspicious activity.

## Non-goals for this phase

- Selecting a distribution, desktop environment, package format, kernel configuration, or AI model.
- Promising absolute privacy or security.
- Collecting mandatory analytics or transmitting behavioral data by default.

## Product pillars

1. **Private by default** — data stays local unless the user deliberately changes that.
2. **Secure by design** — layered controls, least privilege, verifiable system state, and recovery.
3. **Understandable control** — decisions, permissions, and containment actions are visible and explainable.
4. **Resilient operation** — isolation and rollback reduce the blast radius of compromise.
